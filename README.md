# BOSSMAN // STATION

Public face for [BossmanCom](https://github.com/BossmanCom).

Live: https://bossmancom.github.io/

This is a small HUD (clock, Brantford weather, SomaFM) plus a project index. The games live in **[Ani's Arcade](https://bossmancom.github.io/anis-arcade/)**.

## What to click

| Card | Where it goes |
| --- | --- |
| Ani's Arcade | Hub — Runner, Snake, Tower, Chrono Tail Rush |
| Chrono Tail Rush | Fourth cabinet inside the arcade |
| Ani Adventure | Separate click-adventure (rooms / shops / save) |
| Kitsune Blackjack | Card table |
| Scary Classroom | Three.js hide-and-seek |
| Soft Night / Medieval Castle | A-Frame scenes |
| GameFox | Defensive Rust scanner (GitHub, not Pages) |

Standalone copies of Runner / Snake / Tower still exist on Pages for old links. Play them from the arcade.

## Stack

Single `index.html`. No build. Weather from Open-Meteo.

## Local

Open `index.html`, or `npx serve .`
